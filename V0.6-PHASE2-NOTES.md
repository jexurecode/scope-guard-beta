# Scope Guard v0.6 — Phase 2 (Analysis Intelligence)

Focused enhancement to the local heuristic analysis engine. The UI, saved workspace schema, and beta deployment configuration are unchanged.

## Changes

- Recognizes admin editing requests with informal wording such as **“admin tag for editing the web info”**.
- Recognizes explicit **CMS / content editor** requests.
- Provides human-review questions about **one-time content changes versus a self-service editing interface**, editable fields, access, and persistence.
- Offers more specific suggested client replies for admin/content editing and GitHub requests.
- Keeps conservative treatment of simple text updates, links to an admin panel, exclusions, and existing agreed features.
- Adds eight regression cases in `src/lib/analysis-intelligence.test.ts`.

## Important limitations

This is a bounded English-language rule-based prototype, **not AI or a legal contract interpreter**. It may miss features outside its catalog and cannot determine the true contractual scope. A potential change is a suggestion to discuss requirements, not proof of extra billable work.

Existing saved analyses retain their previous snapshots. Create a new analysis to test the updated engine.

## Validation on Windows

```powershell
npm ci
npm test
npm run build
npm run lint
npm run dev
```

Run the provided regression scenario in a **new** analysis, not an old saved analysis. Keep the existing beta `main` branch unchanged until the checks and manual review pass.
