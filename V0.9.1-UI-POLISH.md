# Scope Guard v0.9.1 — Dashboard UI polish

This builds on v0.9, following the approved navy/purple dashboard mockup. No production deployment was performed.

## Changes

- Navy sidebar and purple active state refined to follow the reference.
- Shorter welcome banner with a local SVG laptop, shield, checklist and plant illustration; no external asset requests. Artwork is hidden on phones to prioritize actions and data.
- Metrics appear immediately after the welcome banner. Labels are Projects, Analyses, Potential changes and Need review. Counts and seven-day sparklines still use saved data. Projects shows Saved locally, with no invented timeline. Sparklines are hidden on phones for a compact two-column layout.
- Recent activity is moved ahead of the sample demonstration and Quick Actions on narrow layouts. Request titles and status labels adapt to the actual card width.
- Quick Actions uses a two-by-two card grid: New analysis, New project, Browse history and Try sample. Every action is functional.
- Try sample analysis remains available in a compact strip below the main dashboard. It expands a three-task preview without creating a project or changing stored workspace data. Reduced-motion preferences are respected when scrolling to the preview.
- Headings and form controls explicitly inherit the same sans-serif family. The theme remains light by default; dark mode requires an explicit user choice.
- Desktop, tablet and mobile spacing adjusted. Existing project, analysis and history functionality is preserved.

## Verified

- Actual desktop light/dark and mobile screenshots inspected locally.
- Browser checks passed for expanding/collapsing the sample from both entry points, sample leaving storage untouched, manual theme switching, light default even with a dark system preference, project creation, agreement editing, blog exclusion analysis, and storage persistence after reload.

The existing metric-style test now checks the blue review tone instead of emerald; all count, timeline, accessibility-description and trend assertions remain. No analysis tests were removed or weakened. Analysis rules, import code, hooks and storage schema are unchanged from v0.9.

## Windows check

Extract into a fresh folder and open PowerShell inside `scope-guard`:

```powershell
npm ci
npm test
npm run build
npm run lint
npm run dev
```

Confirm the appearance in your actual Windows browser and on your phone. Check project history, real PDF/DOCX/TXT imports, long agreement scrolling, and keyboard navigation in your environment. Browser checks here used headless Chromium; they do not replace testing on your particular devices or other browser engines.

Keep the existing browser profile and origin when checking saved data. A new localhost port has separate storage. No login, accounts, paid plans or cloud sync have been added; those remain a later milestone.
